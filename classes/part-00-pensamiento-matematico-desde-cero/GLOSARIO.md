| **Incógnita** | Símbolo que representa un valor concreto pero desconocido, determinado por las restricciones del problema. | [015](015-variables-como-cantidades-desconocidas/README.md) |

| **Precedencia** | Orden en que se aplican las operaciones de una expresión. La potenciación asocia por la derecha. | [010](010-orden-de-operaciones-y-parentesis/README.md) |

| **Redondeo bancario** | Regla que redondea el caso 0.5 al par más cercano, para que el sesgo acumulado tienda a cero. | [013](013-aproximacion-redondeo-y-cifras-significativas/README.md) |
| **Valor absoluto** | Distancia de un número al cero. Siempre no negativo y simétrico: |a−b| = |b−a|. | [002](002-enteros-signo-y-recta-numerica/README.md) |

## Cómo usar este glosario

No memorices las definiciones: **usa la columna de clase**. Un término se entiende cuando
puedes ejecutar su demostración y explicar qué comprueba, no cuando puedes recitar su
definición.

```bash
compmath show <clase>    # ficha de la clase donde vive el término
compmath run <clase>     # ejecutar su demostración
```
