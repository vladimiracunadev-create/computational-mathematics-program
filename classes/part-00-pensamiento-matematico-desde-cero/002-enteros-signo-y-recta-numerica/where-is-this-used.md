# ¿Dónde se usa Enteros, signo y recta numérica?

## En computación

Reconstruye la aritmética y el lenguaje matemático básico con el rigor que exige escribir código: cada número tiene dominio, unidad y representación.

Concretamente, **Enteros, signo y recta numérica** aparece siempre que un programa necesita
representar, calcular o verificar el objeto que esta clase define. El laboratorio
`integers_number_line` muestra la versión mínima ejecutable de ese uso.

## En IA y Machine Learning

Toda métrica de un modelo (accuracy, loss, learning rate) es una razón, un porcentaje o una escala. Interpretarlas mal es el primer error de un practicante de IA.

Las partes 14 a 17 del programa consumen directamente este contenido. Si esta
clase es un prerrequisito de una operación concreta de un modelo, escríbelo:
nombrar la dependencia es parte del ejercicio.

## En otros dominios

Cálculo cotidiano, presupuestos, lectura de fórmulas y validación de entradas en software.
